Marks Data Management

The marks displayed on this portal are loaded from the marks.csv file bundled inside the application repository.

Zero Database & Privacy Architecture

This application intentionally does not use external databases or web-based file uploads. This guarantees zero maintenance overhead, zero database costs, and zero risk of unauthorized database modification.

Standard Marks Update Procedure

  1. 1
    Prepare the New Marks CSV

    Ensure the CSV contains a Seat_Number column. Subject names are automatically detected from the remaining column headers.

  2. 2
    Replace the File

    Replace data/marks.csv in the project directory with your verified marks file.

  3. 3
    Verify Locally

    Run python app.py and search for sample seat numbers to verify formatting and score calculations.

  4. 4
    Deploy to Vercel

    Commit the updated CSV to Git and push to your repository (or deploy via vercel --prod). Vercel automatically deploys the updated marks.

Required CSV Header Structure Example:
